# Repository Documentation States History

## 2026-08-02

Removed `deprecated` as a guidance lifecycle state. This repository presents
current preferences, while `history/` preserves useful change rationale and Git
retains exact prior documents. Replacement now means updating consumers and
deleting the superseded guidance rather than keeping redirect or tombstone
documents in active areas.

Stable paths remain preferable when the subject is unchanged. A misleading
path may still be renamed without retaining a permanent compatibility document.
